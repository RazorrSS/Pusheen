## Использование

### Локальный запуск
1. Откройте файл `index.html` в веб-браузере
2. Используйте стрелки для переключения галереи
3. Нажимайте кнопку "Секретное место" для перехода на скрытую страницу
5. На скрытой странице нажмите "СТАРТ" и перетаскивайте Пушинов по экрану

### Деплой
Проект может быть размещен на любом хостинге статических файлов (GitHub Pages, Vercel, Netlify и т.д.).

## Технические характеристики

### Главная страница
- **Слайдер**: Циклическое переключение между 5 изображениями
- **Счетчик**: Отображение текущего положения (X / 5)
- **Анимации**: Плавные переходы, движущийся фон, бесконечная карусель

### Секретная страница
- **Физический движок**:
  - Гравитация: 0.35
  - Коэффициент отскока: -0.65
  - Трение: 0.99
- **Интерактивность**: Поддержка мыши и сенсорного ввода
- **Звук**: Web Audio API синтез

## Функции

| Кнопка | Действие |
|--------|----------|
| ◀ | Предыдущее изображение |
| ▶ | Следующее изображение |
| Секретное место | Переход на скрытую страницу |
| Перетащите Пушина | Управляйте персонажем |

## Совместимость

- **ПК**: Chrome, Firefox, Safari, Edge
- **Мобильные**: iOS Safari, Chrome Android
- **Требования**: HTML5, CSS3, JavaScript (ES6)
